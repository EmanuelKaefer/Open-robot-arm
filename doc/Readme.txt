# Documentation

This folder contains reference documents and data used throughout the project.

## Datasheets&pinouts/
- `TMC5160A_datasheet_rev1.18.pdf` — TMC5160A stepper motor driver datasheet
- `stm32f446mc.pdf` — STM32F446xx microcontroller datasheet
- `STM32F446RE_pins.odt` — Custom pin assignment overview for the STM32F446RE

## Home angle; Limitswitch angle.txt
Reference angles for each joint:
- Home position joint angles (radians)
- Limit switch trigger angles for joints with hard stops

## template/
Document templates used in the project.
