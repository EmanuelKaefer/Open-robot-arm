# Robot Arm Project


This repository contains an ongoing project focused on the development of a 6-DOF robotic arm. The project is part of a school project and may later be extended into a larger final thesis project. The goal is to design and build a functional robotic arm while gaining experience in mechanical design, electronics, embedded systems, and software.

The robotic arm is largely custom built. Most of the mechanical components are designed specifically for this project and manufactured using 3D printing.

The electronics are custom designed for this project, featuring a custom PCB. The board is designed in KiCad and uses an STM32F446RET6 chip along with TMC5160 motor drivers.

The software and control algorithms are developed using MATLAB. It has tools for modeling, simulation, and development of the robot control system. 

The repository will include hardware designs, firmware, control software, and documentation related to the development of the robotic arm. As the project progresses, new features, improvements, and design iterations will be added.
