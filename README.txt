# Robot Arm Project

This repository contains an ongoing project focused on the development of a 6-DOF robotic arm. The project is part of a school project and may later be extended into a larger final thesis project. The goal is to design and build a functional robotic arm while gaining experience in mechanical design, electronics, embedded systems, and software.

The repository includes hardware designs, firmware, control software, and documentation. As the project progresses, new features, improvements, and design iterations will be added.

# Technical Details
* Mechanical: Largely custom built. Most components are designed specifically for this project and manufactured using 3D printing.
* Electronics: Custom designed PCB created in KiCad, utilizing an STM32F446RET6 chip and TMC5160t pro 1.0 motor drivers.
* Software: Control algorithms are developed using MATLAB for modeling, simulation, and deployment.
